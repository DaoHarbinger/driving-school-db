# Вебінтерфейс ІС «Автошкола»

Мінімальний вебінтерфейс до бази `driving_school` (Python 3.10+, Flask, PyMySQL).

## Запуск
Windows: двічі клацнути `start_ui.bat` (або `pip install -r requirements.txt`, потім `python app.py`).
Відкрити http://127.0.0.1:5000 і увійти обліковим записом MySQL з `07_security.sql`.

## Як це влаштовано
- Вхід виконується обліковими записами MySQL; власних користувачів програма не має.
- Кожен запит іде до бази з правами того, хто увійшов: доступ визначають ролі БД,
  бізнес-правила - тригери. Програма лише показує дані та повідомлення бази.
- Меню залежить від ролі (`CURRENT_ROLE()`), але це лише зручність: якщо вручну
  відкрити чужу сторінку, база відмовить, і інтерфейс покаже цю відмову.
- Паролі зберігаються лише в пам'яті сервера; сервер слухає тільки 127.0.0.1.

| Роль | Сторінки |
|---|---|
| менеджер | Курсанти (новий курсант, документ, зарахування, картка курсанта, зміна статусу), Групи і теорія (нова група, серія занять, скасування), Практика (запис, скасування), Іспити (допуск, результати, випуск), Автомобілі (відмітка ТО), Звіти |
| бухгалтер | Фінанси (боржники, історія, оплата/повернення) |
| інструктор | Мої заняття (відмітка «проведено» / «не прийшов») |
| викладач | Відвідуваність теорії |
| аудитор | Журнал аудиту |
| адміністратор | усі сторінки менеджера, бухгалтера й аудитора + Автомобілі (нове авто, списання, закріплення інструктора) + Персонал і доступ |

## Нові облікові записи
Адміністратор створює їх на сторінці «Персонал і доступ» через процедуру `sp_create_account`
(працює з правами root, але дозволяє лише 5 ролей; логін і пароль перевіряє база).
Після `reset_db.bat` облікові записи, створені через інтерфейс, видаляються разом із тестовими даними.
