# ІС для автоматизації роботи автошколи «Автошкола» (MySQL 8.0)

Курсова робота з дисципліни «Організація, адміністрування та захист баз даних».
Автор: Федоренко Олександр Романович.

## Встановлення

```bash
mysql -u root -p --default-character-set=utf8mb4 < install.sql
```

На Windows: подвійний клік на `reset_db.bat` (сам знаходить `mysql.exe`).
УВАГА: перевстановлення скидає всі дані до початкових тестових.

## Файли

| Файл | Призначення |
|---|---|
| `01_schema.sql` | база, 18 таблиць, ключі, обмеження CHECK, індекси |
| `02_triggers_schedule.sql` | контроль розкладу: накладки, кваліфікація, меддовідка, ліміт годин, захист від race condition |
| `03_triggers_integrity.sql` | статуси, місткість груп, оплати й повернення, відвідуваність, іспити |
| `04_seed.sql` | тестові дані (згенеровані `gen_seed.py`) |
| `05_audit.sql` | журнал аудиту, захист платежів і результатів іспитів |
| `06_reports.sql` | функції, представлення, процедури для 9 функціональних задач |
| `07_security.sql` | ролі, користувачі, права, доступ «лише до своїх рядків» |
| `08_performance.sql` | дослідження індексів на 500 тис. записів (результати: `08_performance_results.txt`) |
| `99_tests_triggers.sql` | 62 тестові сценарії тригерів (на чистій базі після 01-03, `mysql --force`) |
| `98_test_race_condition.sql` | тест паралельних сесій |
| `backup/` | резервне копіювання (Linux, Windows), відновлення з перевіркою, PITR |
| `demo/` | сценарій демонстрації на захисті |
| `ui/` | мінімальний вебінтерфейс (Flask): `ui/start_ui.bat`, http://127.0.0.1:5000 |

## Тести

```bash
# на чистій базі
mysql -u root -p < 01_schema.sql
mysql -u root -p < 02_triggers_schedule.sql
mysql -u root -p < 03_triggers_integrity.sql
mysql -u root -p --default-character-set=utf8mb4 --force < 99_tests_triggers.sql
```

Паролі користувачів у `07_security.sql` навчальні.
